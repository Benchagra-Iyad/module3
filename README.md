# Responsive restaurant menu

A front-end exercise from Coursera's Module 3, built to practise responsive layouts with HTML, CSS, and Bootstrap 3.

## What's included

- A restaurant menu with three sections: Chicken, Beef, and Sushi
- A responsive grid that changes across screen sizes
- A collapsible navigation menu on smaller screens
- Links to jump between menu sections and return to the top of the page

## View the project

Open [`module3/index.html`](module3/index.html) in a browser.

The page uses Bootstrap 3 and jQuery from public CDNs, so an internet connection is needed to load those dependencies.

## Project structure

- `module3/index.html` — page structure and navigation
- `module3/style.css` — layout and styling

This is a learning exercise rather than a production application.
